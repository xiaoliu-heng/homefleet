# 验证范围

HomeFleet 为预览版。自动化测试与跨平台构建可以重复执行，实机结果只覆盖已验证环境，不代表所有硬件、系统服务和第三方软件都已验收。

## 自动化验证

公开版本的 GitHub Actions 工作流覆盖以下检查；每个提交的真实结果以仓库 Actions 页面为准。

| 项目 | 内容 |
|---|---|
| Go | Linux、macOS、Windows 的 `go test -race ./...` 和 `go vet ./...` |
| 前端 | 锁文件安装、TypeScript 检查和 Vite 生产构建 |
| 浏览器 | 11 项 Chromium 测试，桌面和手机布局 |
| Docker | Compose 配置校验和标准 Dockerfile 构建 |

Go 测试涵盖注册令牌单次使用、会话与 Agent 权限隔离、机密加密和日志脱敏、任务预览、固定执行范围、并发与单设备互斥、取消、未知结果保护、日志去重续传、备份恢复、指标解析、软件包策略、Git 改动保护及 Agent 更新恢复。

密码校验覆盖首次启动和重置场景：拒绝空白、过短、超过 bcrypt 字节上限和示例占位密码；验证失败保留原密码与会话，成功更新哈希并注销旧会话。

Agent 更新使用真实 HTTPS 下载、文件哈希、临时目录文件替换与独立新版本进程回连验证；操作系统服务管理器在相关恢复测试中使用替身。安装引导测试校验损坏文件、缺失校验和、错误 CA、拒绝 HTTP 和独立下载来源，检查模式不会实际安装服务。

浏览器测试使用独立数据库与明确标记的测试设备；覆盖登录、接入地址切换、项目模板、部分设备预检查失败、手动确认、日志去重、结果核实及 Agent 更新。不会连接正式设备或执行包管理器。

运行方法：

```bash
go test -race ./...
go vet ./...
go build -o bin/homefleet-hub ./cmd/hub
cd web
npm ci
npm run build
npx playwright install chromium
npm run test:e2e
```

## 已验证的实际行为

- Apple Silicon macOS 的真实 CPU、内存、网卡、磁盘、Homebrew 清单及临时只读 Agent 的心跳、离线与恢复。
- macOS 普通用户身份执行的 UID/GID、HOME、PATH、环境变量、原样参数和工作目录；原生启动器处理超过 16 个用户组的场景。
- 临时本地 Git 仓库的固定 commit 部署、脚本、健康检查和未提交改动保护。
- Linux amd64 上 Docker 控制台的健康检查、HTTPS 域名、本地 CA、下载校验和隔离备份恢复。
- Arch 升级在冲突检查阶段失败后，已同步索引仍保留：只读查询能发现待升级包，安装预检查会阻止继续部分升级。

上述记录不包含个人主机地址、账号、凭据、网络拓扑或备份位置。真实环境材料保留在维护者私有目录。

## 仍需逐设备验收

| 平台 / 能力 | 待验证内容 |
|---|---|
| Windows 10/11、NVIDIA | SYSTEM 服务、WinGet、GPU 指标、用户执行器登录/锁屏/注销 |
| Arch、AMD / NVIDIA | 正式包事务、完整升级冲突、包锁、AMD sysfs 与显存类型 |
| Ubuntu | apt 实际安装更新、包锁、GPU 自动识别 |
| Apple Silicon macOS | 各设备 launchd 更新及回退、macmon、睡眠唤醒、Docker Desktop 环境 |
| 路由器 / AP | ICMP/TCP/HTTP 探测、管理链接；不管理固件或网络配置 |
| 更新与恢复 | 各系统真实服务生命周期、断电恢复和无法回连后的人工核实 |

## 首版边界

单管理员、单 Hub；不支持多租户、定时执行、AUR、自定义安装包、固件或网络配置修改。GPU 缺失时显示支持状态及原因，不生成模拟指标。统一内存不展示为独立显存。

项目健康检查未配置时只报告命令结果；脚本超时可能留下子进程，状态会标记待核实。软件源与依赖随时间变化，预览固定操作范围，不承诺远程依赖版本永远不变。备份恢复不会清除 Agent 防重复执行记录。
